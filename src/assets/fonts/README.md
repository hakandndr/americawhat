# Web fonts

Self-hosted copies of the two families the site has always used, taken from
Google Fonts (Anton v27, Archivo v25), latin and latin-ext subsets only.
`src/styles/global.css` declares the same faces, weights and unicode ranges
Google served; `src/layouts/Base.astro` preloads the three latin files.
