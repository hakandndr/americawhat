instruction**; statements such as "production still runs on Hostinger" or "not
deployed yet" describe the time they were written. Current documents: [../README.md](../README.md).

| `staging/` | Staging preflight, rollout and release reports (2026-10-14 → 2026-10-16), including the last manual staging release record (`STAGING-SCHEMA-RELEASE.md`) |
| `sprints/` | Sprint plans and reports: Boss integration, Boss UX/Analytics, integration sprint, design redesign, Boss theme, security remediation, dependency audit |
| `status/` | The long-form status logs replaced by the compact current documents: `CURRENT-STATE`, `HANDOFF` (to 2026-10-16) and `OPERATIONS` (to 2026-10-15) |

Links inside archived files point at the archived set; some refer to documents
by their old names.
